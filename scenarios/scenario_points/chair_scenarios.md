# Chair and Bench Scenario Reference

Filtered from the full scenario list ([scenarios.lua](../scenarios.lua)): every `PROP_HUMAN_SEAT_CHAIR_*` and `PROP_HUMAN_SEAT_BENCH_*` scenario, plus the conditional anim variants from femga's discovery corpus.

- **Scenario** — pass this to `TaskUseScenarioPoint` via a point of this type, or to `TaskStartScenarioInPlaceHash`.
- **Variants** — the conditional anims the scenario can select. Gender and prop requirements are baked into the conditions; an empty list means femga's file has no entry (the scenario may still work with unnamed/default anims).
- A scenario point can only select a variant whose **conditions** are met. That is why a male-only variant silently falls back or makes the ped ignore the scenario.

**Chair scenarios: 95. Bench scenarios: 23. With named conditional anims: 76.**

## Point flags for seating

Baked chair points normally have one of these flags set (see [scenario_point_flags.md](scenario_point_flags.md)):

- `SeatedChair = 58`
- `SeatedBench = 59`
- `SeatedAtTable = 60`
- `SeatedNoBack = 61`

If you create a point manually for a chair, consider setting the matching flag. It is not required for `TaskUseScenarioPoint` to work, but it helps the ambient scenario system understand the point.
